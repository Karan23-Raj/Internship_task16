# Karan Calci ✦

A simple and attractive calculator website made using HTML, CSS, and JavaScript.

## About the Project

Karan Calci is a basic calculator that helps users perform mathematical calculations easily. It has a clean design, colorful buttons, and a simple interface.

## Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Percentage (%)
- Clear (AC) button
- Delete (DEL) button
- Calculation history
- Copy result option
- Keyboard support
- Responsive design for mobile devices

## Technologies Used

- HTML – For website structure
- CSS – For styling and design
- JavaScript – For calculator functionality

## Project Files

- `index.html` – Main structure of the calculator
- `style.css` – Design and styling
- `script.js` – Calculator functions and logic
